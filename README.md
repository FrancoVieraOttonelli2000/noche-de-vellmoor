# Noche de Vellmoor

Juego de acción de horror gótico victoriano y horror cósmico para el navegador, hecho con HTML, CSS y JavaScript puro (Canvas 2D), sin librerías ni imágenes externas: todo el arte se dibuja con código.

- **Modo normal**: niveles al estilo arena, con un jefe cada 6 niveles, enemigos con patrones, élites con afijos, trampas y mapas generados por zonas.
- **Salir de cacería**: modo libre survivor de 10 minutos hasta el amanecer.
- Armas que se transforman, disparo de contra, golpe visceral, vida recuperable, gemas, artes ocultas, atuendos por piezas que cambian la apariencia del cazador, refugio entre partidas y tres dificultades.

## Cómo jugar
Abrí `index.html` en el navegador (doble clic), o serví la carpeta:

```bash
node servir.cjs
```

y entrá a http://localhost:5178.

**Controles**: WASD/flechas moverse · Espacio transformar arma · Shift esquivar · Q vial · R balas de sangre · E arte oculta · F/C objetos · T tienda · P/Esc pausa · M sonido.

La guía completa (armas, enemigos, jefes, atuendos, dificultad) está en [LEEME.md](LEEME.md).
